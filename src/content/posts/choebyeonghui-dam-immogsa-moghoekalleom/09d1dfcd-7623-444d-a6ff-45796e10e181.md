가정교회의 존재목적은 주님의 대사명(마 28:19-20)인 “영혼 구원하여 제자 만드는 것” 입니다. 영혼을 구원하기 위해서 가장 중요한 것은 VIP들을 섬기는 것입니다. 가정교회 사역원에서 사용하고 있는 자가 진단 질문을 통해서 내 자신의 영혼구원에 대한 관심을 체크해 보길 원합니다.

1단계 (VIP 없음, 기도와 섬김 없음)

1)나는 VIP 영혼구원을 꼭 해야한다고 생각지 않는다 ( )

2)나는 VIP 영혼구원에 대해 별로 관심이 없다 ( )

3)나는 VIP를 왜 찾아야 하는지 아직 모르겠다 ( )

4)나는 VIP가 아직 없지만 찾아야 한다고 생각은 한다 ( )

5)나는 지금 나의 VIP를 찾고 있는 중이다 ( )

2단계 (VIP 있음, 기도와 섬김 없음)

6)나는 내가 섬길 VIP를 찾았고 구체적인 대상을 정했다 ( )

7)나는 빕스를 위해 정기적으로 중보기도를 시작했다 ( )

8)나는 빕스를 섬기려고 그의 필요를 헤아려 발견했다 ( )

9)나는 VIP의 인적사항과 기도제목을 목장에 내놓았다 ( )

10)나는 VIP를 섬길 구체적인 계획을 목장에서 나누었다 ( )

3단계 (VIP 있음, 기도와 섬김 있음)

11)VIP의 필요를 구체적으로 섬기고 목장에서 나눈다 ( )

12)VIP가 나의 기도와 섬김에 고마움, 거절 등 반응했다 ( )

13)VIP를 섬기기 위해 목장에서 기도제목을 내놓았다 ( )

14)VIP를 섬기는 일에 목장의 동참을 부탁&의논했다 ( )

15)VIP의 필요를 목장에서 기도제목으로 나누었다 ( )

4단계 (VIP 있음, 기도와 섬김 있음)

16)VIP의 필요를 목장식구들과 함께 섬기고 준목장 시도( )

17)VIP에게 친구&이웃이 되었고 신뢰관계가 만들어졌다 ( )

18)VIP 마음이 열려 목장 모임에 호감과 관심을 가진다 ( )

19)VIP가 목장에 처음으로 온 후 계속 참석을 한다 ( )

20)VIP가 목장식구가 되어 자기 얘기를 활발히 나눈다 ( )

21)VIP에게 예수 영접을 권하여 참여하기로 했다 ( )

과연 여러분은 VIP 섬김의 단계가 어느 단계에 와 있습니까?

고구마전도법에서 외치는 구호가 있습니다. “(전도)나가면 있고 안나가면 없다” VIP도 마찬가지입니다. “VIP 있으면 (전도)되고, VIP 없으면 (전도)안된다” 주님, 저도 한 영혼 구원하기 원합니다.
